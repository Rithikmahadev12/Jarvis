# Figma FlowMaster Cheat Sheet  

**Your 1‑page shortcut & workflow bible for lightning‑fast UI design**  

> Print on A4 (portrait) or keep it on your second monitor for instant reference.  

---  

## 🚀 Quick Navigation  

| Action | macOS | Windows | When to Use |
|--------|-------|---------|-------------|
| **Zoom in/out** | `⌘` `+` / `⌘` `-` | `Ctrl` `+` / `Ctrl` `-` | When you need more detail or a full‑canvas view. |
| **Fit canvas to screen** | `⌘` `1` | `Ctrl` `1` | Quickly reset zoom after deep zooming. |
| **Show/hide UI** | `⌘` `\` | `Ctrl` `\` | Maximize canvas real‑estate for presentations. |
| **Toggle Layers panel** | `⌥` `L` | `Alt` `L` | When you’re juggling many groups or components. |
| **Search (quick jump)** | `⌘` `P` | `Ctrl` `P` | Jump to any frame, component, or page instantly. |

## 🖼️ Layers & Objects  

| Action | macOS | Windows |
|--------|-------|---------|
| **Select next layer** | `⌘` `]` | `Ctrl` `]` |
| **Select previous layer** | `⌘` `[` | `Ctrl` `[` |
| **Group selection** | `⌘` `G` | `Ctrl` `G` |
| **Ungroup** | `⌘` `Shift` `G` | `Ctrl` `Shift` `G` |
| **Lock / Unlock** | `⌘` `Shift` `L` | `Ctrl` `Shift` `L` |
| **Hide / Show** | `⌘` `Shift` `H` | `Ctrl` `Shift` `H` |
| **Duplicate** | `⌘` `D` | `Ctrl` `D` |
| **Copy CSS** (selected) | `⌥` `⌘` `C` | `Alt` `Ctrl` `C` |
| **Select all in frame** | `⌘` `A` (inside frame) | `Ctrl` `A` (inside frame) |

**Tip:** Use `⌥` `⌘` `←/→` (or `Alt` `Ctrl` `←/→`) to nudge objects by 1 px, and `⇧` `←/→` for 10 px steps.
