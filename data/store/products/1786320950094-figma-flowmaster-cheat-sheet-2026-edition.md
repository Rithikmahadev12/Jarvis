## 🚀 Workflow Boosters  

### 1️⃣ **Smart Selection Mode**  
- **Activate:** `⌘ + Shift + S` (mac) / `Ctrl + Shift + S` (win)  
- **What it does:** Highlights all objects with the same fill, stroke, or text style.  
- **Tip:** Use this to instantly recolor a whole UI kit without manual layer hunting.

### 2️⃣ **Batch Rename Layers**  
1. Select multiple layers.  
2. Press `⌘ + R` (mac) / `Ctrl + R`.  
3. Type a naming pattern, e.g., `Btn/Primary/{n}` → Figma auto‑increments `{n}`.  

> **Why it matters:** Consistent naming speeds up hand‑off to developers and keeps the Assets panel searchable.

### 3️⃣ **Instant Component Swapping**  
- **Shortcut:** `⌥ + Click` on a component instance, then drag to another component in the Assets panel.  
- **Result:** The instance swaps instantly while preserving overrides (text, colors).  

> **Pro tip:** Combine with `⌘ + Shift + K` to “Swap with Master” when you need the latest master component.

### 4️⃣ **Prototype Preview from Any Frame**  
- **Shortcut:** `⌘ + P` (mac) / `Ctrl + P`.  
- **How it works:** Opens the prototype overlay for the currently selected frame, bypassing the need to click “Present”.  

### 5️⃣ **Version Snapshots without Leaving the File**  
1. Press `⌘ + Shift + S` → “Create Snapshot
