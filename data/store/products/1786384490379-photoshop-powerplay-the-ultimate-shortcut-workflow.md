## 🔥 Core Navigation (All Panels)

| Action | Windows | macOS |
|--------|---------|-------|
| **Toggle Full‑Screen (no menus)** | `F` | `F` |
| **Show/Hide Rulers** | `Ctrl + R` | `Cmd + R` |
| **Show/Hide Guides** | `Ctrl + ;` | `Cmd + ;` |
| **Snap to Guides / Grid** | `Shift + Ctrl + ;` | `Shift + Cmd + ;` |
| **Zoom In / Out (centered)** | `Ctrl + + / -` | `Cmd + + / -` |
| **Fit on Screen** | `Ctrl + 0` | `Cmd + 0` |
| **Cycle Through Open Documents** | `Ctrl + Tab` | `Cmd + ~` |
| **Toggle Panels (Layers, History, etc.)** | `F7`, `F8`, `F9` | `F7`, `F8`, `F9` |

## ✂️ Selection Toolbox

| Action | Windows | macOS |
|--------|---------|-------|
| **Marquee (Rectangular)** | `M` | `M` |
| **Elliptical Marquee** | `Shift + M` | `Shift + M` |
| **Lasso** | `L` | `L` |
| **Polygonal Lasso** | `Shift + L` | `Shift + L` |
| **Magnetic Lasso** | `Ctrl + Shift + L` | `Cmd + Shift + L` |
| **Quick Selection / Magic Wand** | `W` | `W` |
| **Select All** | `Ctrl + A` | `Cmd + A` |
| **Deselect** | `Ctrl + D` | `Cmd + D` |
| **Reselect Last** | `Ctrl + Shift + D` | `Cmd + Shift + D` |
| **Feather Selection** | `Shift + F6` | `Shift + F6` |

**Pro tip:** Press **`Ctrl + Alt + R`** (Win) / **`Cmd + Option + R`** (Mac) to **record a selection** as a channel—perfect for complex masks later.
