## 🧩 Smart Layer & Mask Workflow

- **Create a Smart Object in one click:** `Cmd/Ctrl + J` → **Right‑click** layer → *Convert to Smart Object*.  
- **Non‑destructive filters:** Double‑click the filter name in the *Properties* panel to edit later.  
- **Quick mask toggle:** `Q`. Paint with black/white to hide/reveal; press `Q` again to exit.  
- **Add a layer mask:** `Alt + Click` the *Add Layer Mask* button (macOS) or `Alt + Click` (Windows).  

**Pro tip:** Use `Shift + Click` on the *Add Layer Mask* button to create a **white mask** (fully visible) instantly, then paint black to hide.
