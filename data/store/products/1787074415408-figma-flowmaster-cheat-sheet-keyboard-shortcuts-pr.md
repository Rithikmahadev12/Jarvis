## 🎯 Quick Reference  

| Category | Shortcut (Windows) | Shortcut (Mac) | Action |
|----------|-------------------|----------------|--------|
| **Selection** | `V` | `V` | Move tool – select & drag objects |
| | `A` | `A` | Frame tool – create frames quickly |
| | `Shift + A` | `Shift + A` | Auto‑layout frame |
| **Layers & Objects** | `Ctrl + G` | `⌘ + G` | Group selection |
| | `Ctrl + Shift + G` | `⌘ + Shift + G` | Ungroup |
| | `Alt + Drag` | `Option + Drag` | Duplicate while moving |
| | `Ctrl + D` | `⌘ + D` | Duplicate selection |
| **Transform** | `K` | `K` | Scale tool |
| | `R` | `R` | Rotate tool |
| | `Shift + Arrow` | `Shift + Arrow` | Nudge 10 px (or 10 pt) |
| **Text** | `T` | `T` | Text tool |
| | `Ctrl + B` | `⌘ + B` | Bold |
| | `Ctrl + I` | `⌘ + I` | Italic |
| | `Ctrl + Shift + L` | `⌘ + Shift + L` | Align left |
| **Navigation** | `Space + Drag` | `Space + Drag` | Pan canvas |
| | `Ctrl + 1` | `⌘ + 1` | Zoom to 100 % |
| | `Ctrl + 2` | `⌘ + 2` | Zoom to selection |
| | `Ctrl + 3` | `⌘ + 3` | Zoom to fit |
| **Components** | `Ctrl + Alt + K` | `⌘ + Option + K` | Create component |
| | `Ctrl + Alt + B` | `⌘ + Option + B` | Detach instance |
| **Export** | `Ctrl + Shift + E` | `⌘ + Shift + E` | Export dialog |
| | `Alt + Shift + S` | `Option + Shift + S` | Slice tool (quick slice) |
| **Versioning** | `Ctrl + Shift + G` | `⌘ + Shift + G` | Show/hide version history |
| **Comments** | `C` | `C` | Add comment mode |
| **Search** | `Ctrl + /` | `⌘ + /` | Quick actions & plugin search |

> **Tip:** Hold `Ctrl` (Windows) / `⌘` (Mac) while pressing a shortcut to reveal its “contextual” variant in the Quick Actions menu.
