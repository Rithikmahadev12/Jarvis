# Photoshop Power Shortcuts: 1‑Page Pro Cheat Sheet  

> **Your fast‑track to mastering Adobe Photoshop—no more hunting through menus.** Print, pin, or keep on your desktop for instant recall.

---

## 1️⃣ Selection & Navigation  

| Shortcut | Action | Pro Tip |
|----------|--------|---------|
| **V** | Move Tool (drag layers) | Hold **Shift** while dragging to constrain movement to 45° increments. |
| **M** | Marquee (Rectangular) | Press **Shift** for a perfect square; **Alt/Option** draws from center. |
| **L** | Lasso (Freehand) | Double‑tap **L** → **Polygonal Lasso**; triple‑tap → **Magnetic Lasso**. |
| **Ctrl + A** (Cmd + A) | Select All | Press **Ctrl + D** (Cmd + D) to deselect instantly. |
| **Ctrl + J** (Cmd + J) | New layer from selection | Use after any selection for non‑destructive edits. |
| **Spacebar** (hold) | Hand Tool (pan) | Combine with **Alt/Option** to zoom in/out while panning. |
| **Ctrl + + / -** (Cmd + + / -) | Zoom In/Out | **Ctrl + 0** (Cmd + 0) fits canvas to window; **Ctrl + 1** (Cmd + 1) sets 100 %. |

## 2️⃣ Layers & Masks  

| Shortcut | Action | Pro Tip |
|----------|--------|---------|
| **Ctrl + G** (Cmd + G) | Group selected layers | Name groups on the fly: **Ctrl + G**, then **F2** (Enter) to rename. |
| **Ctrl + E** (Cmd + E) | Merge selected layers | Use **Shift + Ctrl + E** (Shift + Cmd + E) to merge all visible layers into a new one. |
| **Ctrl + Alt + G** (Cmd + Option + G) | Create clipping mask | Shortcut toggles mask on/off—great for texture overlays. |
| **Ctrl + Shift + N** (Cmd + Shift + N) | New layer dialog | Press **Ctrl + Shift + Alt + N** (Cmd + Shift + Option + N) for a new layer *without* dialog. |
| **Alt + Click** (Option + Click) on layer thumbnail | Load layer transparency as a selection | Perfect for quick selections of complex shapes. |
| **Ctrl + I** (Cmd + I) on mask thumbnail | Invert mask | Combine with **Shift** to invert *and* hide mask temporarily. |
| **Ctrl + / (Slash)** (Cmd + /) | Show/hide all panels | Clears screen for a distraction‑free view. |

---

## 3️⃣ Brush & Paint  

| Shortcut | Action | Pro Tip |
|----------|--------|---------|
| **B** | Brush Tool | Press **[** / **]** to shrink/expand brush size by 1 px; **Shift + [ / ]** changes size by 10 px. |
| **Shift + B** | Cycle through brush presets | Drag the **Brush Preset Picker** while holding **Shift** for rapid preview. |
| **Alt + Right‑Click** (Option + Control‑Click) | Sample & paint (Eyedropper + Brush) | Hold **Alt** and drag to blend colors on the fly. |
| **Ctrl + Alt + Shift + K** (Cmd + Option + Shift + K) | Brush Settings dialog | Save custom brushes as **.abr** files for team sharing. |
| **X** | Switch foreground/background colors | Double‑tap **X** to toggle back to the previous color pair. |
| **D** | Reset colors to default (black/white) | Useful after heavy color swapping. |
