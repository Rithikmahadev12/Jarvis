## 📚 Navigation & Selection

| Action | Windows | macOS | Tips |
|--------|---------|-------|------|
| **Zoom in / out** | `Ctrl` `+` / `Ctrl` `-` | `⌘` `+` / `⌘` `-` | Hold `Space` + scroll for fluid zoom |
| **Fit to screen** | `Shift` `Ctrl` `1` | `Shift` `⌘` `1` | Great after deep zoom |
| **Show/hide UI** | `Ctrl` `\` | `⌘` `\` | Maximize canvas real‑estate |
| **Select all** | `Ctrl` `A` | `⌘` `A` | Use `Shift` + `A` to select **all layers** in current frame |
| **Select next layer** | `Alt` `↑` / `Alt` `↓` | `Option` `↑` / `Option` `↓` | Cycle without moving mouse |
| **Select similar** | `Ctrl` `Shift` `A` | `⌘` `Shift` `A` | Picks same type (text, shape, component) |
