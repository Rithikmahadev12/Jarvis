# Figma FlowMaster: The Ultimate One‑Page Shortcut & Workflow Cheat Sheet  

---  

## 🎯 Quick Navigation  

| Action | macOS | Windows/Linux |
|--------|-------|----------------|
| **Zoom In / Out** | `⌘ + +` / `⌘ + -` | `Ctrl + +` / `Ctrl + -` |
| **Fit Canvas to Screen** | `⌘ + 1` | `Ctrl + 1` |
| **Zoom to Selection** | `⌘ + 2` | `Ctrl + 2` |
| **Show/Hide UI** | `⌘ + \` | `Ctrl + \` |
| **Pan** | Hold `Space` and drag | Hold `Space` and drag |
| **Jump to Frame** | `⌘ + Shift + O` | `Ctrl + Shift + O` |

**Tip:** Double‑tap `Space` to toggle between pan and hand tool instantly.

## ✏️ Core Editing Shortcuts  

| Action | macOS | Windows/Linux |
|--------|-------|----------------|
| **Select / Move** | `V` | `V` |
| **Frame (Auto‑Layout)** | `⌘ + Option + G` | `Ctrl + Alt + G` |
| **Rectangle** | `R` | `R` |
| **Ellipse** | `O` | `O` |
| **Pen / Edit Vector** | `P` | `P` |
| **Text** | `T` | `T` |
| **Slice** | `S` | `S` |
| **Duplicate** | `⌘ + D` | `Ctrl + D` |
| **Copy / Paste** | `⌘ + C` / `⌘ + V` | `Ctrl + C` / `Ctrl + V` |
| **Paste in Place** | `⌘ + Shift + V` | `Ctrl + Shift + V` |
| **Group / Ungroup** | `⌘ + G` / `⌘ + Shift + G` | `Ctrl + G` / `Ctrl + Shift + G` |
| **Bring Forward / Backward** | `⌘ + ]` / `⌘ + [` | `Ctrl + ]` / `Ctrl + [` |
| **Align to Pixel Grid** | `⌘ + Shift + P` | `Ctrl + Shift + P` |

**Tip:** Hold `Shift` while dragging a shape to constrain proportions *and* snap to the nearest pixel grid.
