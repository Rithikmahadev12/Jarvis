# Figma FastTrack: 1‑Page Shortcut & Workflow Cheat Sheet  

> **Your 60‑second lift‑off guide to designing faster, collaborating smoother, and never losing your place again.**  

---  

## 🎯 Quick Navigation  

| Action | macOS | Windows/Linux |
|--------|-------|----------------|
| **Zoom to 100 %** | `⌘` + `0` | `Ctrl` + `0` |
| **Zoom In / Out** | `⌘` + `+ / -` | `Ctrl` + `+ / -` |
| **Fit Canvas to Screen** | `⌘` + `1` | `Ctrl` + `1` |
| **Show/Hide UI** | `⌘` + `\\` | `Ctrl` + `\\` |
| **Toggle Rulers** | `⇧` + `R` | `Shift` + `R` |
| **Jump to Next/Prev Frame** | `⌘` + `]` / `[` | `Ctrl` + `]` / `[` |
| **Search Layers** | `⌘` + `F` | `Ctrl` + `F` |

> **Tip:** Press `⌘` + `Shift` + `?` (or `Ctrl` + `Shift` + `?`) to open the full shortcut reference inside Figma.

## 🖌️ Layers & Objects  

| Action | macOS | Windows/Linux |
|--------|-------|----------------|
| **Select All** | `⌘` + `A` | `Ctrl` + `A` |
| **Select Parent** | `⌘` + `↑` | `Ctrl` + `↑` |
| **Select Children** | `⌘` + `↓` | `Ctrl` + `↓` |
| **Group / Ungroup** | `⌘` + `G` / `⌘` + `Shift` + `G` | `Ctrl` + `G` / `Ctrl` + `Shift` + `G` |
| **Duplicate** | `⌥` + `Drag` | `Alt` + `Drag` |
| **Lock / Unlock** | `⌘` + `Shift` + `L` | `Ctrl` + `Shift` + `L` |
| **Hide / Show** | `⌘` + `Shift` + `H` | `Ctrl` + `Shift` + `H` |
| **Bring Forward / Send Backward** | `⌘` + `]` / `[` | `Ctrl` + `]` / `[` |
| **Bring to Front / Send to Back** | `⌘` + `Shift` + `]` / `[` | `Ctrl` + `Shift` + `]` / `[` |

> **Workflow Nugget:** After selecting multiple layers, press `⌘` + `[` repeatedly to “nest” them automatically into a new frame—speedy component creation without right‑click menus.
