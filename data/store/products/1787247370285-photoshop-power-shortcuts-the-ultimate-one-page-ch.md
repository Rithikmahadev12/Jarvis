# Photoshop Power Shortcuts: The Ultimate One-Page Cheat Sheet

> **Quick reference for the most powerful Photoshop keyboard shortcuts and workflow hacks.** Perfect for freelancers, designers, and anyone who wants to shave minutes (or hours) off every project.  

---

## 🔥 Core Navigation

| Action | Windows | macOS |
|--------|---------|-------|
| **Toggle Full‑Screen Mode** | `F` (cycle) | `F` (cycle) |
| **Show/Hide Rulers** | `Ctrl + R` | `Cmd + R` |
| **Zoom In / Out** | `Ctrl + + / -` | `Cmd + + / -` |
| **Fit on Screen** | `Ctrl + 0` | `Cmd + 0` |
| **Hand Tool (temporarily)** | Hold `Space` | Hold `Space` |
| **Cycle Through Open Docs** | `Ctrl + Tab` | `Cmd + ~` |

## ✂️ Selection & Transform

| Action | Windows | macOS |
|--------|---------|-------|
| **Marquee (Rectangular)** | `M` | `M` |
| **Lasso (Freehand)** | `L` | `L` |
| **Quick Mask Mode** | `Q` | `Q` |
| **Free Transform** | `Ctrl + T` | `Cmd + T` |
| **Warp Transform** | `Ctrl + Shift + T` | `Cmd + Shift + T` |
| **Scale Proportionally** | Hold `Shift` while dragging | Hold `Shift` while dragging |
| **Resize from Center** | Hold `Alt` while scaling | Hold `Option` while scaling |

> **Tip:** After hitting `Free Transform`, press `Enter` to commit **or** `Esc` to cancel—no need to click the checkmark.

## 🎨 Color & Brush Mastery

| Action | Windows | macOS |
|--------|---------|-------|
| **Swap Foreground/Background** | `X` | `X` |
| **Toggle Brush Size** | `]` / `[` | `]` / `[` |
| **Toggle Brush Hardness** | `Shift + ]` / `Shift + [` | `Shift + ]` / `Shift + [` |
| **Sample Color from Canvas** | `Alt` (hold) | `Option` (hold) |
| **Open Color Picker** | `Ctrl + Alt + Shift + K` | `Cmd + Opt + Shift + K` |
| **Toggle Brush Panel** | `F5` | `F5` |

> **Pro tip:** Hold `Alt` + `Shift` while dragging a brush to **smoothly taper** the stroke edge.
