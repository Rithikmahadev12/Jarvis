# Figma FlowMaster Cheat Sheet – 2026 Edition  

**Your all‑in‑one, single‑page reference for mastering Figma’s fastest shortcuts, hidden commands, and workflow hacks.** Perfect for designers, UI engineers, and anyone who spends more time in the canvas than at a desk.  

---  

## 🎯 Quick Navigation  

| Action | macOS | Windows | Tip |
|--------|-------|---------|-----|
| **Zoom to 100 %** | `⌘` `1` | `Ctrl` `1` | Press again to toggle between 100 % and previous zoom. |
| **Zoom to Fit** | `⌘` `2` | `Ctrl` `2` | Instantly frames all visible layers. |
| **Zoom to Selection** | `⌘` `3` | `Ctrl` `3` | Handy after selecting a group. |
| **Pan / Hand Tool** | Hold `Space` | Hold `Space` | Keep pressed while dragging; no need to switch tools. |
| **Toggle UI** | `⌘` `\` | `Ctrl` `\` | Hide panels for a distraction‑free view. |

## ✂️ Selection & Layers  

| Action | macOS | Windows | Tip |
|--------|-------|---------|-----|
| **Select All** | `⌘` `A` | `Ctrl` `A` | Use within a frame to select its contents only. |
| **Deselect** | `Esc` | `Esc` | Works even when a text field is active. |
| **Select Next Layer** | `⌥` `↑` | `Alt` `↑` | Cycle forward; combine with `Shift` to select multiple. |
| **Select Parent Frame** | `⌥` `⌘` `←` | `Alt` `Ctrl` `←` | Jump up the hierarchy instantly. |
| **Group / Ungroup** | `⌘` `G` / `⌘` `Shift` `G` | `Ctrl` `G` / `Ctrl` `Shift` `G` | Grouping also creates auto‑layout if the selection contains frames. |
| **Lock / Unlock** | `⌘` `Shift` `L` | `Ctrl` `Shift` `L` | Locking prevents accidental moves while you fine‑tune other elements. |

## 📐 Shape & Vector Editing  

| Action | macOS | Windows | Tip |
|--------|-------|---------|-----|
| **Pen Tool** | `P` | `P` | Double‑click to finish a path; hold `Shift` for 45° angles. |
| **Boolean Operations** | `⌘` `⌥` `M` (Union) <br> `⌘` `⌥` `S` (Subtract) <br> `⌘` `⌥` `I` (Intersect) | `Ctrl` `Alt` `M` / `S` / `I` | Select multiple shapes first. |
| **Convert Point** | `⌘` `⌥` `C` | `Ctrl` `Alt` `C` | Click a corner point to toggle between corner and smooth. |
| **Scale** | `K` (Scale tool) | `K` | Drag from a corner while holding `Shift` to maintain proportions. |
| **Smart Selection** | `⌘` `Shift` `O` | `Ctrl` `Shift` `O` | Turns a group into a single editable vector (useful for icons). |
