## 🛠️ Pro Workflow Tips  

### 1. **Speed‑Select with “Select Subject”**  
- Press `Shift + Ctrl + Alt + S` (Windows) / `Shift + ⌘ + Option + S` (macOS) → **Select Subject**.  
- Instantly isolates people, animals, or objects—perfect for quick masks.

### 2. **Non‑Destructive Editing with Smart Objects**  
- Convert any layer to a Smart Object (`Ctrl + J` → right‑click → **Convert to Smart Object**).  
- Apply filters, transformations, or warps without permanent pixel changes.  

### 3. **Batch‑Apply Layer Styles**  
1. Select the target layer.  
2. `Alt + Click` the **fx** icon on another layer to copy its style.  
3. `Alt + Shift + Click` the **fx** icon on the destination layer to **paste** the style.
